# Architecture Decision Records (ADR)

Folder ini berisi catatan keputusan arsitektur (*Architecture Decision Record*) beserta konteks dan konsekuensinya.

## Daftar ADR

| No | Judul | Status |
|---|---|---|
| [ADR-001](0001-pemeriksaan-bentrok-sinkron.md) | Pemeriksaan bentrok dilakukan secara sinkron saat pengajuan perubahan jadwal | Proposed |
| [ADR-002](0002-data-ruang-jadwal-terpusat.md) | Data ruang dan jadwal disimpan terpusat, bukan disalin ke tiap modul | Proposed |

## Format

Setiap ADR memakai lima bagian: **Status**, **Context**, **Decision**, **Consequences**, dan **Compliance**.

## Daftar Status

- **Proposed**: diusulkan, belum disepakati.
- **Accepted**: disetujui dan berlaku.
- **Deprecated**: tidak lagi dianjurkan.
- **Superseded**: digantikan oleh ADR lain.
